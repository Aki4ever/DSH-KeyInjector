## 二、各页说明

### UI-001 · 密钥库（默认）

- **入口**：应用启动后的默认页 / 侧边栏「密钥库」
- **页面元素**：顶部工具区（显示明文开关、全部探测、新增密钥）；密钥列表（状态色点、别名、厂商标签、自定义标签、掩码、SHA-256 短指纹、探测状态、优先级、探测/复制指纹/启停/删除操作）；侧边栏计数徽标；底部状态栏（密钥后端、密钥数与落点数）
- **本图要点**：三条演示密钥均以掩码形式显示（`sk-d…7890`、`sk-a…7890`），验证「明文不默认暴露」；侧边栏显示 3 条密钥与 4 条审计记录

### UI-002 · 密钥库（新增密钥弹窗）

- **入口**：密钥库 → 右上角「＋ 新增密钥」
- **页面元素**：厂商下拉选择；厂商信息卡（环境变量名、API 基址、申请入口与「打开」按钮、探测方式说明与反例提示）；别名、密钥明文、优先级、标签、备注输入；底部安全提示
- **本图要点**：厂商信息卡会随所选厂商实时切换，把「该厂商用哪个环境变量、去哪申请」直接呈现在录入现场，减少填错

### UI-003 · 注入中心（dry-run 计划已生成）

- **入口**：侧边栏「注入中心」→ 选择落点与密钥 →「生成注入计划」
- **页面元素**：第一步选择区（落点下拉、密钥下拉、落点说明与反例、目标文件路径、键名）；第二步核对区（落点、写入路径、文件状态、注入键名、使用密钥与指纹、差异预览、确认写入/放弃按钮）；回滚：最近注入记录
- **本图要点**：差异预览以绿色标注新增行，且**密钥在差异中仍然掩码**（`sk-d…7890`），验证「预览即安全」；未点「确认写入」前不会有任何落盘动作

### UI-004 · 健康探测（默认）

- **入口**：侧边栏「健康探测」
- **页面元素**：四类统计卡（有效 / 无效 / 额度限流 / 未探测）；逐项探测列表（状态色点、别名、厂商、探测状态、耗时、探测时间、结果说明、探测按钮）
- **本图要点**：演示环境未做真实探测，因此统计为「未探测 3」，如实反映状态，不伪造结果

### UI-005 · 审计日志（默认）

- **入口**：侧边栏「审计日志」
- **页面元素**：筛选标签（全部 / 注入 / 回滚 / 密钥变更 / 探测）、刷新按钮；时间线列表（状态色点、动作名、时间戳、说明、目标文件、备份路径、回滚按钮）

## 三、截图生成方式

本项目的页面台账并非用系统 `screencapture` 截取，而是由应用自身的 **WKWebView 渲染快照**产生：

```bash
KEYINJECTOR_HOME=/tmp/keyinjector-demo \
KEYINJECTOR_STORE=file \
KEYINJECTOR_WEB_DIR="$PWD/web" \
KEYINJECTOR_WINDOW_RECT="60,60,1240,820" \
KEYINJECTOR_SNAPSHOT_DIR="$PWD/docs/screenshots" \
KEYINJECTOR_SNAPSHOT_DEMO_FILE="/tmp/keyinjector-demo/demo.zshrc" \
./.build/debug/KeyInjectorApp
```

**为什么不用 `screencapture`**：本机未授予终端屏幕录制权限，实测两者均失败
（`could not create image from display` / `could not create image from rect`）。
改用应用内快照后有三个额外好处：① 不需要系统权限；② 只包含页面内容，无桌面干扰；
③ 窗口尺寸可固定，出图可复现。

**环境隔离保证**：截图使用独立数据目录 `/tmp/keyinjector-demo` 与临时目标文件，
**不读写用户真实密钥、钥匙串与配置文件**（已实测核对 `~/.zshrc` 与 `~/.codex/auth.json` 修改时间未变）。
