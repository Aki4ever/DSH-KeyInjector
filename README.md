# 账号管理器 (KeyInjector)

macOS 原生架构的 AI API Key 账号管理工具：集中保管密钥、识别每个 Key 可用的模型、展示模型剩余额度与更新日期，并把密钥注入 DSH / Codex 等宿主配置。

## 最新版本：v2.0.0

- **密钥库按 key 别名分区**：一把 key 一个分区，分区标题显示别名、厂商、状态与「模型 N 个」计数，可折叠；页头支持按别名 / 厂商 / 模型名 / 端点搜索，并可「仅看未探测 / 异常」。分区数据与 CLI `keyinject keys --grouped` 同口径。
- **从 key 自身端点识别可用模型**：点「识别模型」会实测该 Key 端点（优先自定义 Base URL）的 `/models`，兼容 OpenAI / Gemini / Ollama / 裸数组 / 键值映射五种响应；实测失败时逐级降级到宿主声明映射与名称推断，**每一行都标注来源与依据**。实测公司AI综合 key 读回 19 个模型身份（宿主只声明了 6 个）。凡未识别到模型，界面如实说明原因，不伪造列表。
- **key 详情视图**：点 key 名或「详情」进入全屏详情，含身份、健康探测、可提供的模型、注入落点、最近审计五段；「改为探测鉴权」与「重新探测模型」分开摆放，避免把「通不通」和「有哪些模型」混为一谈。
- **模型清单与密钥库整合**：密钥库里每张密钥卡直接展示它提供的模型（标注来源、置信度与绑定依据）；「模型清单」页为 **DSH + Codex 双宿主总览**，同一模型在两边的别名自动合并，并显示网关事实源与同步计划。
- **DSH 落点键名以宿主声明为准**：修复 `dsh-desktop` 落点硬编码 `DEEPSEEK_API_KEY` 导致「注入成功但宿主读不到」的静默失效，现按 `settings.yaml` 的 `apiKeyEnv` 动态解析。
- **Codex 桌面端模型菜单无缝打通**：自动生成 `model_catalog_json`，将中间商网关的 DeepSeek V4.1、Gemini 3.8 Flash 模型直接注册到 Codex 顶部下拉菜单中，支持即选即用。
- **本地高强度加密引擎 (AES-GCM)**：全面取代系统钥匙串，彻底杜绝 macOS 登录密码弹窗骚扰，实现 100% 零阻断一键注入。
- **DSH 与 Codex 极简双宿主矩阵**：清洗 8 个冗余干扰落点，专注桌面端核心注入场景。
- **极简「⚡ 一键注入生效」**：毫秒级完成 Key 智能匹配、Dry-run 校验、自动时间戳备份与原子写入。
- **密钥可视化管理**：支持 Key 别名、Secret 明文与中转 Base URL 自定义修改。

## 安全边界

- 应用默认只显示掩码与 SHA-256 短指纹；只有显式打开「显示明文」才向前端回传明文。
- 模型识别**只在用户点击时联网**，不做任何后台轮询；不做第三方中转，不写入任何宿主配置。
- 发现结果缓存 `model-cache.json` 只含掩码、指纹、模型名、端点与时间，**不含明文**。
- 推断（T5）结果一律标注「推断」并降权显示，绝不当作事实。
